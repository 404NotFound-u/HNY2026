# Новогоднее поздравление 2026 🎄

Этот репозиторий содержит простую, но атмосферную веб-страницу с анимированным новогодним поздравлением к **2026 году**.

## 📄 Содержимое

- **`HNY2026.html`** — единственный HTML-файл, содержащий всё необходимое:  
  - праздничное поздравление «С Новым Годом! 2026 🎄»  
  - анимацию падающего снега (`❄`) в трёх размерах  
  - плавное «пульсирующее» масштабирование текста  
  - тёмный новогодний фон и золотистый текст с мягким свечением  

Всё реализовано с использованием **чистого HTML, CSS и JavaScript** — без внешних зависимостей, фреймворков или изображений.

## 🎨 Особенности

- Полноэкранный режим с центрированным текстом  
- 120 уникальных снежинок с разной скоростью, размером и прозрачностью  
- Адаптивная анимация, работающая в любом современном браузере  
- Общая тематическая палитра: тёмно-синий фон, белый снег, золотой текст  

## ▶️ Как использовать

Просто откройте файл `HNY2026.html` в любом веб-браузере — ничего устанавливать не нужно!

Отлично подходит для:
- личного новогоднего настроения  
- демонстрации базовых навыков веб-анимации  
- отправки друзьям как мини-открытка
